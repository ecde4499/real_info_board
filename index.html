과제 확인 정보

실제 데이터: 실제 데이터 조회는 공개 Open-Meteo API에서 현재 서울 2m 기온을 읽습니다. API는 Asia/Seoul 시간대를 요청하고 브라우저 조회 시각도 KST로 기록합니다.

실제 이틀: 성공 조회일을 KST 날짜 키로 한 건만 저장합니다. 서로 다른 실제 날짜에 한 번씩 성공 조회해야 실제 2건이 됩니다. 미래 날짜를 가짜로 채우지 않습니다.

실패 보존: 실패 재생 중에는 마지막 정상값을 지우지 않고 STALE/ERROR 상태로 표시합니다.

공개 안전: API 키·로그인·개인정보 입력이 없습니다.
